# 掼蛋出牌助手 · 手机网页版（阶段1·手动录入）

纯前端、离线可用的掼蛋出牌建议工具。手机浏览器打开即用，**手动点选「我的手牌 + 台面牌」→ 立即给建议**。
共用与 Python 引擎一致的逻辑（`guandan/` 的移植版），不依赖摄像头/网络。

## 文件
| 文件 | 作用 |
|---|---|
| `index.html` | 手机界面（Tailwind，移动优先）|
| `guandan.js` | 引擎：牌型分析 `classify` / 比较 `beats` / 出牌生成 / 建议 `advise`（移植自 `guandan/core.py`+`play.py`，浏览器与 Node 通用）|
| `test.js` | Node 测试，28 项，对齐 Python 单测 |

## 本地验证
```bash
node webapp/test.js          # 应 28/28 通过
```

## 在手机上使用
1. 选「当前级牌（打几）」。
2. 切到「点牌→我的手牌」，在牌面板点出自己的牌（同一张最多 2 张，因两副牌）。
3. 若轮到你跟牌：切到「点牌→台面牌」，点出上家出的那手牌（会实时显示识别出的牌型）；
   若你是首家，勾选「我是首家」。
4. 点「获取出牌建议」，显示「出牌/过牌 + 具体牌 + 理由」。

## 部署到 GitHub Pages
仓库 Settings → Pages → 选分支与根目录后，访问 `https://<用户名>.github.io/lover-run-2025/webapp/` 即可。
（也可直接把 `webapp/` 里两个文件拷到任意静态空间。）

## 边界与下一步
- 当前为**手动录入**；**摄像头自动认牌**是后续升级（需要能跑视觉模型/有摄像头的环境）。
- 建议为启发式，适合训练/复盘参考；**升级为搜索/强化学习**可显著提高建议质量（后续壁垒工作）。
- 眼镜版：同一套 `guandan.js` 逻辑可复用，把「录入」换成第一视角识别、「显示」换成耳机播报。
