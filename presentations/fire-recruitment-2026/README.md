# 2026 年度国家消防救援局招收消防员 · 网页 PPT

单文件 HTML 横向翻页演示,使用[歸藏 PPT Skill](https://github.com/op7418/guizang-ppt-skill)的**瑞士国际主义风格(Style B)**生成。

## 打开方式

直接用浏览器打开 `index.html` 即可,无需本地服务器。

- `← / →` 或滚轮 / 触屏滑动:翻页
- `ESC`:索引缩略图
- `B`:静态 / 动态切换(低功耗模式,断网或投屏卡顿时使用)

## 设计

- **风格**:瑞士国际主义(无衬线 + 网格 + 单一锚点色)
- **主题色**:🔵 克莱因蓝 IKB(`#002FA7`)—— 呼应消防救援"火焰蓝"
- **动效**:Motion One(本地 `assets/motion.min.js` + CDN 双保险)
