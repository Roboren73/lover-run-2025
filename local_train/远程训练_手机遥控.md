# 手机在外面遥控办公室 4090 训练（远程训练指南）

目标：把**装着 4090 的 Windows 笔记本**留在办公室一直开着，人在外面用**手机**遥控它训练，不用带电脑。

> 重要：训练机必须是**带 NVIDIA 4090 的 Windows 笔记本**。Intel 款 MacBook(A2159) 没有 NVIDIA、不能跑 CUDA 训练，外接 4090 到 Mac 也不行——MacBook 这件事用不上。

## 方案 0：用「迷你主机 + 4090 显卡坞(eGPU)」当办公室训练服务器

如果你的 4090 是**外置显卡坞(eGPU)**，它必须接一台 **Windows 主机**（macOS 无 N 卡驱动，接 Mac 不行）。推荐买一台带雷电口的 Windows 迷你主机专门放办公室接它。

**选购要点**
- ★**接口必须匹配显卡坞**：坞子是**雷电(Thunderbolt 3/4)**就买带"Thunderbolt 4"的迷你主机；坞子是 **Oculink** 就买带 Oculink 的（如 Beelink GTi 系列，更快）。普通 USB-C ≠ 雷电，接不了。
- 配置够用即可（重活是 4090 干）：CPU 现代 6–8 核+（i5/i7 12代+ 或 Ryzen7）、内存 32GB(最低16)、1TB NVMe SSD、Windows 11。
- 确认显卡坞 PSU 功率够喂 4090（桌面 4090 满载 ~450W）。
- 参考方向（搜"型号 + Thunderbolt/Oculink"确认）：Intel NUC 13/12 Pro、Minisforum、ASUS NUC、Beelink GTi。

**配好后**：迷你主机装 NVIDIA 驱动 + 训练环境(`README_本地4090训练.md`)，再按下面方案 A 装 Tailscale + JupyterLab，手机即可遥控。

---

## 方案 A（推荐）：Tailscale 私有网络 + JupyterLab 网页

体验最接近 Colab：手机浏览器点格子跑训练，算力是你自己的 4090，断网也不停。

### 1) 让手机能从外面连到办公室电脑：装 Tailscale
- 在 **4090 笔记本**装 Tailscale（tailscale.com/download），用某账号(Google/微软/邮箱)登录。
- 在**手机**也装 Tailscale，用**同一个账号**登录。
- 这样两台设备进同一个私有网络。在笔记本的 Tailscale 里能看到它的地址，形如 `100.x.x.x`。
- 好处：**不用公网IP、不用设路由器**，手机用任何网络(4G/家里WiFi)都能连到办公室电脑，且加密安全。

### 2) 在 4090 笔记本上跑 JupyterLab（一次设置）
在已装好训练环境的目录（见 `README_本地4090训练.md`）里：
```powershell
venv\Scripts\activate
pip install jupyterlab
:: 绑定到所有网卡，方便手机经 Tailscale 访问；设一个登录密码/token
jupyter lab --ip=0.0.0.0 --port=8888 --no-browser
```
启动后终端会打印一个带 `token=...` 的网址，记下这个 token。

### 3) 手机访问
手机浏览器打开：`http://<笔记本的Tailscale地址>:8888`（如 `http://100.x.x.x:8888`），
输入 token 登录 → 新建 Notebook → 像 Colab 一样跑：
```python
from ultralytics import YOLO
m = YOLO("yolov8s.pt")
m.train(data=r"D:\guandan\merged\data.yaml", imgsz=960, epochs=120, batch=-1, device=0)
```
训练在办公室 4090 上跑，**手机关屏/断网都不影响**，回来刷新看进度。

## 方案 B（最傻瓜）：Chrome 远程桌面
1. 4090 笔记本：Chrome 浏览器装「Chrome 远程桌面」(remotedesktop.google.com)，设一个 PIN。
2. 手机：装「Chrome 远程桌面」App，同一 Google 账号登录。
3. 手机点开那台电脑 → 看到桌面 → 直接操作（双击运行 `train.py` 等）。
- 优点：零网络知识、最直观；缺点：手机上操作桌面偏小，适合"点一下开训练、看看日志"。

---

## 必做：让电脑一直在线、训练不被打断
- **电源**：插着电；Windows「电源和睡眠」→ 睡眠设为"从不"；「其他电源设置→选择合上盖子的功能」→ 合上盖子时"不采取任何操作"。
- **网络**：尽量插网线，最稳。
- **断线续跑**：
  - 用 Jupyter 的话，训练在内核里跑，浏览器断开不影响（回来重连即可）。
  - 用命令行的话，训练本身会一直跑；想更稳可在后台运行或用任务计划。
- **看结果**：训练完 best.pt 在 `runs_guandan\...\weights\`，用 `export_onnx.py` 导出，再上传到仓库 `webapp/`。

---

## 一句话总结
**Tailscale(让手机连得到) + JupyterLab(手机网页跑训练)**，就能把办公室 4090 变成"你私人的、无额度限制的 Colab"，手机在外面随时开练、看进度。
