> 这份给「跑在用户 Windows 电脑上的本地 Claude Code 会话」看。
> 之前的准备工作都在云端会话完成并提交到分支 `claude/dou-dizhu-video-analysis-zilvga`。
> 用户是新手、跟着做就行；每一步先解释再执行，遇到报错帮他解决。

## 背景（已完成的事）
- 52 类认牌模型已训好（Colab，mAP≈0.995）；现在要扩成 **54 类**，加 **小王/大王**。
- 这副牌是「三A扑克 AAA」：**小王=纯黑白印刷，大王=彩色印刷**，图案相同、靠颜色区分。
- 真牌照片已采集并分类好：`local_train/cards/small/`(小王黑白 7 张)、`local_train/cards/big/`(大王彩色 8 张)。
- 已有脚本：`crop_cards.py`(裁牌面)、`gen_joker_data.py`(合成+自动打标)、`merge_jokers.py`(合并54类)、`train.py`、`export_onnx.py`。
- 合成数据集 `joker_dataset/`(116M) 没入库，需本地用脚本重新生成（见下）。

## 硬件
- 一块 **RTX 4090（雷电外置显卡坞 eGPU）** 接在这台 Windows 上（用户挖过矿，驱动多半已装）。

## 执行步骤（Windows PowerShell，建议纯英文路径如 D:\guandan）

### 0. 确认显卡
```powershell
nvidia-smi
```
看到 `NVIDIA GeForce RTX 4090` 和 `CUDA Version` 即 OK。
- 报 `不是内部或外部命令` → 装最新 NVIDIA 驱动（GeForce 官网/GeForce Experience），重启后再试。
- 看不到 4090 → 排查雷电坞连接（换雷电口、确认坞供电、Windows「雷电控制中心」里已授权该设备）。

### 1. 装训练环境（一次性）
按 `README_本地4090训练.md` 第一节。要点：**先装带 CUDA 的 PyTorch**（cu124），再装 ultralytics。
```powershell
python -m venv venv; venv\Scripts\activate
pip install --upgrade pip
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu124
python -c "import torch; print('CUDA:', torch.cuda.is_available(), torch.cuda.get_device_name(0))"  # 必须 True + 4090
pip install ultralytics onnx onnxruntime pillow numpy pyyaml
```

### 2. 生成大小王数据集（含自动标注，0 手工标注）
```powershell
cd local_train
python crop_cards.py cards cards_crop
python gen_joker_data.py --cards cards_crop --backgrounds backgrounds --per-class 200 --out joker_dataset
```

### 3. 拿到 52 类基础数据集
- 用户在 Colab 下过 `Playing-Cards-4`（augmented-startups，52类）。让他打包下载到本地，或用 roboflow 包+API key 下载。
- 放到本地，记下其 `data.yaml` 路径。

### 4. 合并成 54 类
```powershell
python merge_jokers.py --base 路径\Playing-Cards-4 --jokers joker_dataset --out merged
```
合并后类序：原 52 类 + `joker_small`(id52) + `joker_big`(id53)。

### 5. 训练 + 导出
```powershell
python train.py --data merged\data.yaml --model yolov8s.pt --imgsz 960 --epochs 120
python export_onnx.py --imgsz 960
```
- 显存不够就 `--batch 8` 或 `--imgsz 640`。

### 6. 上线到网页
- 把导出的 `best.onnx` 改名上传到 `webapp/` 覆盖旧模型。
- 网页类别要从 52 改成 54：把 `merged\data.yaml` 里的 `names`（54个，最后两个是 joker_small/joker_big）更新进 `webapp/camera.html` 的 `CLASS_NAMES`。顺序必须和 data.yaml 完全一致。

## 注意
- eGPU 走雷电带宽比台式机 PCIe 略低，但 YOLO 训练是算力瓶颈，影响很小，正常训即可。
- 真牌是斜放拍的，裁切后框略含背景，能用；以后想更准可把牌平放正拍重采。
