# 一步步把训练笔记本传到 Colab

笔记本文件：本仓库 `vision/train_colab.ipynb`（仓库是公开的，Colab 能直接读）。

---

## 准备
- 一个 **Google 账号**（Gmail 即可）。
- 建议用**电脑 + Chrome 浏览器**（手机也能用，但操作没电脑顺手）。

---

## 方法一（推荐）：让 Colab 直接从 GitHub 打开，不用下载

1. 浏览器打开 **https://colab.research.google.com** ，右上角登录你的 Google 账号。
2. 通常会自动弹出「打开笔记本」窗口；如果没弹，点左上角 **文件 → 打开笔记本**。
3. 在弹窗顶部选 **GitHub** 这个标签页。
4. 在搜索框里粘贴仓库地址：
   ```
   roboren73/lover-run-2025
   ```
   按回车。
5. 下面会出现一个 **「分支 / Branch」下拉框**，把它从 `main` 改选成：
   ```
   claude/dou-dizhu-video-analysis-zilvga
   ```
6. 列表里会出现 `vision/train_colab.ipynb`，**点它**。笔记本就在 Colab 里打开了。
7. 开 GPU：菜单 **代码执行程序 / 运行时 → 更改运行时类型 → 硬件加速器选 GPU(T4) → 保存**。
8. 跑起来：菜单 **代码执行程序 / 运行时 → 全部运行**。
   - 第一次会提示"此笔记本不是你创建的，是否运行"——点 **仍然运行 / 继续**。
9. 跑到第 3 格「数据集」时，按格子里的注释，把 `YOUR_API_KEY` 换成你在
   roboflow.com 注册后拿到的 Key（这步需要你本人操作账号）。改完再继续运行后面的格子。
10. 全部跑完后，最后一格会自动把 **best.pt / best.onnx** 下载到你电脑。

> 想保存你改过的笔记本：**文件 → 在云端硬盘中保存副本**（直接存回 GitHub 需要额外授权，不必）。

---

## 方法二：先下载到电脑，再上传

1. 在 GitHub 打开文件 `vision/train_colab.ipynb` 页面，点 **Download raw file**（下载原始文件）按钮，存到电脑。
2. 打开 https://colab.research.google.com → **文件 → 上传笔记本** → 选刚下载的 `train_colab.ipynb`。
3. 之后同方法一的第 7 步起（开 GPU → 全部运行 …）。

---

## 常见问题
- **找不到 GPU 选项 / 跑得很慢**：确认第 7 步选了 GPU 并保存；免费额度紧张时可能要等一会儿或换时段。
- **运行几小时后断了**：免费版有时长限制，属正常；记得训练完及时下载模型。
- **数据集那步卡住**：必须先有 roboflow 的 API Key，并把第 3 格的 workspace/project/version 换成你所选数据集页面给出的值。
- **手机操作**：用手机浏览器选「桌面版网站」会更好点；但首次强烈建议用电脑。
