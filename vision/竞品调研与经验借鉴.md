# 竞品调研 & 经验借鉴（2026-07）

调研 GitHub + 网络后的结论：**你的技术路线是主流、正确的**；认牌训练已达业界最好水平；
但在「出牌策略强度」和「连续视频/牌局跟踪工程」上，别人比你成熟，有现成经验和轮子可借。
而你瞄准的**实体牌 + 第一视角眼镜**方向，恰恰是几乎没人做过的空白——这既是难点，也是你的独特价值。

## 一、和你几乎一样的项目（重点对标）

### ⭐ reportyao/guandan-ai-coach —— 最像你、且部分已走在前面
「AI掼蛋教练：实时识别 + 策略推荐」，Android。和你目标高度重合，值得逐条学：
- 认牌：**YOLOv8-nano，54 类端到端**（直出 cardId 0-53，不用二次匹配）——**印证了你要扩到54类的方向**。
- 部署：ONNX Runtime Mobile + **INT8 量化**（手机端提速）；本地优先，云端 GLM-4V 因不稳定被停用。
- 策略：4 维启发式（减手牌35% / 控场25% / 配合20% / 牌力保留20%）——和你的引擎思路几乎一致；另有"团团转"变体，实测均分 +0.47→+0.90。
- **关键区别**：它靠**截屏识别线上掼蛋（微乐/边锋）**，是数字牌面，比实体牌好认得多；也因此属于"线上开挂"的灰色地带。你做**实体牌+摄像头**，更难但更正当。
- ✅ 可借鉴的工程经验（都是踩过的坑）：
  - **密集牌难识别**：它遇到"54帧里只有5帧检出"，靠**提高ROI切块重叠(0.18→0.32)+降置信度阈值(0.5→0.3)**解决 → 你识别扇形手牌会遇到同样问题，同样对策。
  - **牌局状态机**：跟踪该谁出牌、各家出过什么；弱信号会让回合判断卡死 → 要做鲁棒状态机。
  - **自适应帧率**(150-1000ms，按温度/电量)降耗~60%；**策略LRU缓存**(按局面hash跳过重算) → 眼镜/手机续航关键。

### hamza93-ai/Playing-Card-Detection-YOLOv8 —— 和你CV栈一模一样
52类、Roboflow数据、Colab T4、YOLOv8s、200轮、640px、**ONNX浏览器+摄像头实时**。
- 成绩 **mAP50 99.4% / mAP50-95 90.1%**——和你的 0.995 基本持平，**说明你的认牌训练已是业界最好做法**。
- ⚠️ 它自曝的限制正是你要面对的：**浏览器纯CPU推理只有1-5 FPS**(GPU能30+)、**依赖良好光照**、要手动选onnx。
  → 眼镜/视频实时必须用**量化模型 + 移动端NPU/ncnn/ONNX Runtime**，别指望浏览器CPU跑视频。

## 二、出牌策略：别人比你强的地方（可直接升级）

你现在是**启发式**引擎（够用、可解释）。但更强的路线已有成熟成果：

| 方案 | 说明 | 对你 |
|---|---|---|
| **DanZero / DanZero+** (arXiv 2210.17087 / 2312.02561) | 掼蛋SOTA，用 Deep Monte-Carlo(DMC) 分布式RL，碾压启发式规则AI，是掼蛋AI的学术标杆 | 想让建议更强，这是终极目标引擎 |
| **DanLM** (dashidhy/DanLM) | 自对弈RL + 序列建模，零领域知识玩掼蛋/斗地主 | 新范式，可关注 |
| **rlcard** (datamllab, 3.5k★) / **DouZero** (kwai, 4.6k★) | 通用牌类RL框架，含斗地主/掼蛋环境 | 现成训练框架，不用从零写 |
| 商业「Guandan Card: AI」App | **残局Minimax求解器 + 贝叶斯推断对手手牌** | 两个高价值升级点：残局精算 + 猜对手牌 |
| **welkin03/guandan-ai** (开源) | 108张双副牌解析、逢人配(红桃级牌)、合法出牌生成、四人状态、配分 | **可直接复用规则引擎**，省得自己写全套规则 |
| NUAA-guandan (41★) | 模仿学习+深度RL(ActionValueNet Q网络) | 学习式引擎参考实现 |

**建议**：短期继续用启发式（快、能解释）；中期把引擎接口留好，接入 DanZero+/rlcard 这类RL引擎，或加"贝叶斯猜手牌 + 残局Minimax"两招提升建议质量。

## 三、智能眼镜方向：几乎无人区（你的独特价值）

- 网络调研证实：AR眼镜实时认牌**技术可行**（CNN认牌、端侧AI保隐私、眼镜摄像头常见1280×720），
  已有 VisionClaw 等"常在AI眼镜代理"研究，但**没有成熟的掼蛋/实体牌眼镜助手开源项目**。
- **Ray-Ban Meta 等封闭消费眼镜**拿不到实时视频流、且在博彩圈引发作弊争议——避开，选**开放SDK的AR眼镜**。
- 端侧推理保隐私（不上传第三方服务器）是共识，正好契合你"本地4090/手机推理"的布局。

## 四、给你的行动结论

1. **认牌**：路线已对、成绩已达标；重点转向**难样本**（扇形手牌、斜视角、暗光、密集牌），
   借鉴coach的**ROI切块+阈值调参+状态机**。
2. **54类**：方向被竞品验证，继续。部署走**量化+移动端runtime**，不要靠浏览器CPU跑视频。
3. **策略**：预留引擎接口，中期升级到 **DanZero+/rlcard** 或加 **贝叶斯猜牌+残局Minimax**；
   规则层可考虑复用 **welkin03/guandan-ai**。
4. **眼镜**：这是你的差异化护城河，选开放SDK眼镜，端侧推理，耳机语音提示优先。
5. **定位**：坚持"练习/复盘辅导"，线上截屏开挂和正式赌局要划清界限（调研里博彩圈对眼镜作弊反应强烈）。
