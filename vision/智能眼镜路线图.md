# 终极目标：智能眼镜掼蛋助手 · 总路线图

> 最终形态：戴上智能眼镜打掼蛋，系统实时识别**我手里的牌**和**桌面上各家打出的牌**，
> 结合掼蛋引擎给我出牌建议（耳机悄悄提示或镜片显示）。
> 定位：**技术辅导/练习工具**。仅在朋友知情的练习局或复盘中使用；
> 不用于赌钱、正式比赛——那种场合属于作弊，坚决不做。

## 一、为什么现在做的每一步都在通往眼镜

眼镜形态 = 「摄像头 + 算力 + 认牌模型 + 掼蛋引擎 + 提示通道」。
其中**认牌模型和掼蛋引擎与硬件无关**，先用手机把它们练到能用，
最后一步只是把"摄像头和屏幕"从手机换成眼镜。

```
[摄像头画面] → [YOLO 认牌(54类)] → [牌局状态跟踪] → [掼蛋引擎出牌建议] → [提示(语音/HUD)]
      ↑手机/眼镜        ↑正在扩到54类        ↑待做              ✅已完成           ↑待做
```

## 二、三阶段路线

### 阶段 1（已基本完成）：手机 = 眼镜的替身
- ✅ 掼蛋引擎 + 牌型分析 + 出牌建议（已验证）
- ✅ 手机网页版：手动输入 + 摄像头拍照认牌（52 类，mAP≈0.995）
- 🔜 54 类（加大小王）：数据已备好，等 4090 训练
- 用法：打牌时手机拍一下手牌/桌面 → 网页给建议。体验是"拍照式"的，
  这就是眼镜体验的最小原型。

### 阶段 2：识别能力打磨（4090 本地训练）
1. 54 类模型训练上线（`local_train/本地会话_从这里开始.md` 全步骤）。
2. **第一视角手牌识别强化**——眼镜看自己手牌是斜视角+扇形排列+角标互相遮挡，
   是整个项目最难的 CV 问题。对策：
   - 用眼镜/俯视角度自拍手牌照片补充训练集（脚本管线已能自动合成+打标）；
   - imgsz 960→1280 提升小角标识别；必要时训练"只认左上角标"的专用模型。
3. **连续视频 + 牌局状态跟踪**（从"拍照"升级为"直播"）：
   - 抽帧推理 + 多帧投票去抖动；
   - 状态机：累计谁出过什么牌、剩牌估计，喂给引擎；
   - "哪家打的牌"归属：按桌面区域划分（上家/对家/下家区）判断。

### 阶段 3：眼镜硬件接入（两条可行形态 + 一个坑）
| 形态 | 说明 | 难度 |
|---|---|---|
| A. 眼镜只当**显示器** | XREAL/Rokid 等观影眼镜接手机，手机继续当摄像头+算力，建议显示在镜片上 | 低，买来即用 |
| B. 眼镜当**摄像头**（终极形态） | 带摄像头+开放 SDK 的 AR 眼镜（如 Rokid、INMO、Vuzix 等国产/企业级），视频流回传手机或家里 4090 主机推理，耳机语音提示 | 中高，需按 SDK 开发 |
| ⚠️ 坑：封闭消费眼镜 | Ray-Ban Meta 这类不开放实时视频流给第三方 App，做不了 | 避开 |

- 算力布局：推理放手机(onnx web/ncnn)够用；要更强可回传给 4090 主机（家里/办公室，Tailscale 内网穿透已有方案文档）。
- 提示通道优先**耳机语音**（实现简单、不挡视线），HUD 显示做增强。
